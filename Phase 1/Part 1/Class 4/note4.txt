### Pointer : A variable that holds the memory address of another
              variable. It allows indirectly accessing and manipulating
              the values stored in a memory location.
              -> asterisk (*) is used to declare a pointer.
              -> (*) - value-at-operator / dereference
              -> (&) - address-of-operator / reference
              -> Pointer doesn't have its own datatype, it borrows the type
                 of the variable its storing the address of. When a pointer is incremented,
                 it increases by the size of the data type to which it points.
              -> value of null poiter = NULL or nullptr.
              -> When a pointer is declared to an array, the poiner points to the 
                 memory address of the first element of the array.

### Reference : A variable is an alias for an existing variabl. It provides an alternative name
                for an object, allowing to access and manupulate the object using different names. Once 
                a reference variable is initialized, it cannot be changed to refer to a different object.

                -> Must be initialized at the time of declaration.
                -> Cannot be reassigned to a different varaible.
                -> Works as an alternative name for that variable throughout its scope.
