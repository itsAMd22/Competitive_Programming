# Custom Header :

    ->File extension : .h or .hpp
    ->Syntax : #include "header_file_name"
    
# Macros : Allows reusability of chunks of code.
    ->Syntax : #define macro_name code_to_be_excecuted

# Boolean Algebra : Wise to use parantheses while working with bitwise operators.

    ->NOT(~) : Takes in a single boolean value, and then negates it.
    ->OR(|)  : Takes in two boolean values, outputs true if atleast one is true.
    ->AND(&) : Takes in two boolean values, outputs true if both one is true.
    ->XOR(^) : Takes in two boolean values, outputs true if only one of them is true.
    ->Left Shift(<<) : multiplying with 2.
    ->Right Shift(>>) : dividing with 2.

# Bit Manipulation : For a number num,
    -> k-th bit is set if (num & (1 << k)) is true and unset otherwise.
    -> to set k-th bit, num |= (1 << k).
    -> to unset k-th bit, num &= ~(1 << k).
    -> is odd if (num & 1) is true and even otherwise.
    -> to toggle k-th bit,  num ^= (1 << k).
    -> A power of 2 always has a single set bit which is the MSB.

# Array : Fixed-size collection/data structure of similar data items stored in contigous memory locations.
    -> 1D Array : data_type array_name [size] = {value1, value2, ... valueN};
    -> Multi-dimentional Array  : data_type arr_name[size1][size2]......[sizen];
    -> Elements can be accessed using index.
    -> Array can be passed to a user-defined function.
        -->> Calling     : func_name(arr_name);
        -->> Declaration : return_type func_name(data_type array[]);
# Strings: 
    ->Strings in C are null-terminated.
    ->Standard input stops at spaces; alternatives(getline(), getchar()) handle full lines.
    ->Newline characters in buffers must be handled properly using getchar(), buffer clearing loops, or adjusted format specifiers.
    ->Safe string handling prevents buffer overflows.
    ->Built-in functions simplify string manipulation.


# Time Complexity : The time complexity of an algo estimates how much time the algo will use 
                    for some input. The idea is to represent the efficiency as a funtion whose 
                    parameter is the size of the input. Its usually expressed using big O notation,
                    which denotes the upper bound of the time complexity in the worst case scenario.

    -->> Types: 0(1) - constant time, O(n) - linear time, O(n^2) - quadratic time, O(n^3) - Cubic time,
                O(2^n) - exponential time, O(n!) - factorial time, O(log n) - logarithmic time, O(n logn)-
                Linearithmic time, O(n^k) [k is contant] - Polynomial time and O(k^n) [k is constant] - 
                exponential time.
    -->> Around 10^8 operations can be done in 1s.
    -->> Preference: O(1) > O(log n) > O(n) > O(n logn) > O(n^2) > O(2^n) > O(n!)



********************************************log2(n) = (ln n / ln 2)****************************************************



# Space Complexity : Space complxity of an algorithm quantifies the maximum amount of space or memory taken by an
                     algorithm to run as a function of the size of the input data.

***Constant factors(exp : 100 in 100n) are ignored in TC and SC, but the code does run that amount of time (100n), not only n.


# Subarray : Continous part of an array. (n*(n+1)/2 subarrays)
            Exp : {1}, {1,2}, {1,2,3} , {2,3} , {2,3,4,5} are all subarrays of {1,2,3,4,5} but {1,2,5} is not.
# Substring : Continous part of a string.
            Exp : "a","b","c","d","ab","bc","abc","def" are substrings of "abcdef" but "abef" is not.            

***Sub-array/string of n size container count = n*(n+1)/2

# Subsequence : A sequence derived from another by deleting some(possibly none) elements without changing the order.
            Exp : {1,2,4,6} is a subsequence of {1,2,3,4,5,6,7,8,9}.
            -->> Subsequence are possible for both array and string.

***Sub-sequence of n size container count = 2^n (including empty subsequences).

# Subset : A set obtainable from another set. (order doesnt matter)
            Exp : {1,4,3} is a subset of {1,3,4,7}
***Subset of n size container count = 2^n (including empty subset).

# Bitmasking : Used to generate subsets using bit manipulation tricks, a mask is buitl up corresponding to the set and
                then all those elements are taken in the subset if the corresponding bit in the mask is set or on and 
                left out otherwise.
