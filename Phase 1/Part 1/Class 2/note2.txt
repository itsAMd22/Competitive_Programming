*** Function Overloading : 

Two functions can have the same name if the number and/or type 
of argument passed is different.Based on the type of parameter 
passed during the function call, the corresponding function is called.

** EXAMPLE : 

	// same name different arguments
	int test() { }
	int test(int a) { }
	float test(double a) { }
	int test(int a, double b) { }

	// Error code
	int test(int a) { }
	double test(int b){ }

*** Defaut Arguments(Paramters) :

-> The 2nd(or more) argument cannot be passed without passing the 1st(or previous) arguments.
-> Once we provide a default value for a parameter, all subsequent parameters must also have 
   default values. For example,

	// Invalid
	void add(int a, int b = 3, int c, int d);

	// Invalid
	void add(int a, int b = 3, int c, int d = 4);

	// Valid
	void add(int a, int c, int b = 3, int d = 4);

-> If we are defining the default arguments in the function definition instead of the function
   prototype, then the function must be defined before the function call.

	-> Sum formulas :

		-->> ∑i = (1+2+3+ ..... +n) = n*(n+1)/2
		-->> (1+3+5+ ..... +(2n-1)) = n^2
		-->> (2+4+6+ ..... +2*n) = n*(n+1)
		-->> ∑(i^2) = n*(n+1)*(2*n+1)/6
		-->> ∑(i^3) = (n*(n+1)/2)^2 = (∑i)^3
		-->> ∑(ki), multiples of k = k*(n*(n+1)/2)
		-->> ∑i - ∑(ik), not multiples of k = (n*(n+1)/2) - (k*(m*(m+1)/2))
		-->> ∑i*(i+1) = ∑(i^2 + i) = ∑i^2 + ∑i = ∑i/2 + ∑i = ∑i*3/2
		-->> ∑(i-1)*(i)*(i+1) = ∑i*(i^2-1) = ∑i^3 - ∑i = (∑i)^2 - ∑i

	-> Progression  :
		-->> Arithmatic : Common difference , d = a(n) - a(n-1)
			>> nth term = a1 + (n-1)*d
			>> sum till nth term    = ∑(a1 + (i-1)*d) 
						= ∑a1 + ∑(i-1)*d 
						= na + d*(∑(i) - ∑1) 
						= na + d*n*(n+1)/2 - dn 
						= n/2 * (2a1 + (n-1) * d)
		-->> Geometric  : Common fraction , r = a(n) / a(n-1)
			>> nth term = a1 * r^(n-1).
			>> sum till nth term    = a1(r^n - 1) / (r - 1) , when 	r > 1
						= a1(1 - r^n) / (1 - r) , when r < 1
						= n * a1 , when r == 1
	-> Counting : 

		-->> Factorial : no. of ways to arrange n disctinct elements in a line.
		-->> Commbination : P(n,k) no. of ways to choose k distinct elements from n elements.
		-->> Permuatation : C(n,k) no. of ways to choose k distinct elements from n elements and arrange them in a line.
		
		*** Order matters in permuation.
		*** C(n,k) * k! = P(n,k) = n! / (n-k)!

	-> Logarithm : 
		
		-->> loga (a) = 1
		-->> loga (1) = 0
		-->> loga (b^n) = n * loga (b)
		-->> loga (b.c) = loga b + loga c 
		-->> loga (b/c) = loga b - loga c
